# V3XV0ID AV Client: downloads

The desktop app for [VexVoid](https://www.vexvoid.com): the VJ mixer, the music and the game.

This repository holds **release files only**; the source code is private.
Get the latest version from [Releases](https://github.com/b0ase/vexvoid-releases/releases/latest), or from [vexvoid.com/download](https://www.vexvoid.com/download).

Each release includes `SHA256SUMS.txt`. Check a download with `shasum -a 256 -c SHA256SUMS.txt`.

Play in the browser instead, no install needed: [vexvoid.com/game](https://www.vexvoid.com/game).
